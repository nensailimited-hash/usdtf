USDTF

Experimental USD-Referenced Token on BNB Smart Chain

About the Project

USDTF is an experimental BEP-20 token deployed on the BNB Smart Chain. The project was created for research, development, and testing purposes within decentralized finance environments.

The token uses an upgradable proxy architecture (ERC1967 / UUPS) and interacts with decentralized liquidity pools for on-chain price discovery.

USDTF is not affiliated with Tether, USD₮, or any centralized issuer and does not represent a claim on fiat currency.

Project Status

USDTF is considered a legacy and experimental token. The project is not actively marketed and is maintained primarily for testing, learning, and architectural experimentation.
