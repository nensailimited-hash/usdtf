# USDTF – USD Finance Token

USDTF is an experimental BEP-20 token deployed on the BNB Smart Chain.

The project was created for research, development, and testing purposes
within decentralized finance (DeFi) environments.

USDTF uses an upgradable proxy architecture (ERC1967 / UUPS) to allow
controlled contract upgrades while maintaining the same proxy address.

## Key Information

- Network: BNB Smart Chain
- Token Standard: BEP-20
- Architecture: Upgradable Proxy (ERC1967 / UUPS)
- Version: V9
- Contract Address (Proxy):
  0x4028E1E613eEE7ceaB20071C266cfcA554E44890

## Project Status

This token is experimental and provided for educational and testing purposes.
It is not affiliated with Tether, USD₮, or any centralized issuer and does not
represent a claim on fiat currency.

No guarantees are made regarding price stability, value, or future development.
